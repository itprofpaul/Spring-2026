
Final Project: Build a Complex Web App

Design and build a polished multi-feature web application that demonstrates the skills you have developed throughout this course.
Project Overview

For your final project, you will create a complex web app using HTML, CSS, and JavaScript. Your project should show that you can move beyond a small demo and build something with multiple connected features, a clean interface, and organized code.

Your project must be published as a new page or section on your existing GitHub Pages site.

What Counts as a Complex Web App?

A complex web app is more than a single button and a single response. It should have enough features and structure to feel like a real application instead of a quick class demo.

Your project should include:

    multiple connected features
    clear user interaction
    dynamic updates with JavaScript
    organized code
    a polished user interface

Required Project Features

Your final project must include all of the following:

    A clear purpose
    Your app should solve a problem, support a task, provide a tool, or create an interactive experience.
    At least 3 major interactive features
    Examples: search, filtering, adding/removing items, editing content, generating results, tracking progress, puzzle logic, scoring, multiple views, saved data, or keyboard interaction.
    DOM manipulation with JavaScript
    Your project must dynamically update content on the page.
    User input handling
    Your app must respond to user choices, typing, buttons, forms, or other interactions.
    Data structures in JavaScript
    Use arrays, objects, or both to manage your app's information.
    Functions organized by purpose
    Your code should not be one long script. Separate responsibilities where possible.
    Styling with CSS
    Your app should look intentional, readable, and visually organized.
    Client-side validation or rules
    Examples: prevent blank input, prevent duplicates, require valid selections, or stop invalid actions.
    At least one advanced course concept
    Examples include localStorage, fetch/API use, query parameters, loading states, timers, keyboard input, game states, or separation of UI and logic.
    Deployment on GitHub Pages
    The final version must work on your live site.

Complexity Expectations

Your project should demonstrate that you can combine multiple techniques into one experience. Strong projects will usually include several of these:

    multiple sections or views
    reusable functions
    organized data structures
    conditional rendering or state changes
    user-friendly messages and feedback
    saved data with localStorage
    an API connection or external data source
    searching, sorting, or filtering
    game logic or progression logic
    responsive design considerations

A project that is technically correct but too small or too simple may not meet the final project standard.

Technical Requirements

    Use HTML for structure
    Use CSS for layout and design
    Use JavaScript for functionality
    Keep files reasonably organized
    Use meaningful variable and function names
    Indent and format your code so it is readable
    Your project must run correctly in the browser without instructor fixes
    Your project must be published on GitHub Pages

Minimum Deliverables

    a completed web app
    a working link on GitHub Pages
    a link from your main site or navigation to the project page
    code that is readable and reasonably organized

What Will Hurt Your Grade

    a project that is too small or too simple
    broken functionality
    missing required features
    poor organization that makes the project hard to follow
    a project that only works locally and not on GitHub Pages
    very limited styling or unclear layout
    copying a tutorial too closely without meaningful customization
